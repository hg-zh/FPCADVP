# Glucose input is not distributed

Obtain the Hall et al. (2018) glucose measurements from the sources cited in the [application README](../README.md). Supply the prepared `data_1.csv` with columns `id`, `time`, and `gl`. The README specifies timestamp format, units, row order, and the historical preprocessing required for exact reproduction.

Place this file here locally, or set `GLUCOSE_DATA_FILE` to an external CSV. Raw-source-to-CSV assembly is not supplied. No data, saved fits, or downloaded files are included in the public distribution.
